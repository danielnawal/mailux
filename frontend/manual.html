    📋 Gestión de Listas de Contactos

    Las listas son grupos de contactos a los que enviarás emails. Antes de crear una campaña, necesitas una lista con contactos.

    Crear una Nueva Lista

    1. Haz clic en "Listas" en el menú
    2. Haz clic en "+ Nueva lista"
    3. Ingresa un nombre descriptivo (ej: "Clientes VIP")
    4. Haz clic en "Crear"
    ✅ Tu lista está creada y lista para recibir contactos.

    Subir Contactos (CSV)

    La forma más rápida de agregar muchos contactos es mediante un archivo CSV.

    Paso 1: Preparar el CSV

    Crea un archivo con este formato:

    email,name juan@example.com,Juan Pérez maria@example.com,María García carlos@example.com,Carlos López

    Paso 2: Subir en Mailux

    1. En la lista, haz clic en "Subir contactos (CSV)"
    2. Selecciona tu archivo
    3. Haz clic en "Subir"

    Paso 3: Revisar Resultados

    Recibirás un mensaje con:

    Importados: 1,245 Inválidos: 5
    ⚠️ Los emails inválidos se ignoran automáticamente (formato incorrecto, caracteres especiales, etc.)

    Campos Válidos en CSV

    Campo Requerido Ejemplo
    email Sí juan@example.com
    name No (opcional) Juan Pérez

    📧 Crear y Enviar Campañas

    Paso 1: Ir a Campañas

    Haz clic en "Campañas" en el menú → Luego "+ Nueva campaña"

    Paso 2: Completar Formulario

    Campo Descripción Ejemplo
    Nombre interno Solo para ti (no lo ve el usuario) "Black Friday 2024"
    Lista Elige la lista a enviar "Clientes VIP"
    Asunto Asunto del email "Oferta exclusiva: 50% off"
    Nombre remitente Tu nombre (cómo apareces) "Mi Tienda"
    Email remitente Email desde el que se envía "promo@mitienda.com"
    Cuerpo HTML Contenido del email Ver abajo

    Paso 3: Contenido (HTML)

    Puedes escribir HTML personalizado o usar una plantilla predefinida.

    Ejemplo Simple:

    <h1>¡Hola {{nombre}}!</h1> <p>Tenemos una oferta especial para ti:</p> <a href="https://mitienda.com/ofertas" style="display: inline-block; background: #667eea; color: white; padding: 15px 30px; text-decoration: none; border-radius: 5px;"> VER OFERTA </a> <p>¿No quieres recibir estos emails?</p> {{unsubscribe_link}}

    Variables Disponibles

    Variable Resultado Ejemplo
    {{nombre}} Nombre del contacto Se reemplaza con "Juan"
    {{unsubscribe_link}} Link para desuscribirse Genera un link automático

    Paso 4: Enviar Inmediatamente

    1. Haz clic en "Guardar borrador"
    2. La campaña se guarda con estado "Borrador"
    3. Haz clic en botón "Enviar" (azul)
    4. Confirma: "¿Enviar a X contactos?"
    5. ¡Listo! Verás estado "Enviando..."

    Paso 5: Programar para Después (Opcional)

    1. En el campo "Programar envío", ingresa fecha/hora
    2. Formato: 2026-06-10 09:00
    3. Haz clic en "Guardar borrador"
    4. Estado cambiará a "Programada"
    5. Se enviará automáticamente en la fecha
    ✅ Tu campaña se envió o está programada.

    ¿Qué se rastrea?

    Aperturas

    Cuándo abre cada usuario el email

    🖱️

    Clics

    Qué links clickeó y cuántas veces

    Rastreo de Aperturas

    Mailux inserta automáticamente un píxel invisible (1x1 px) en cada email.

    Cuando el usuario abre el email, el píxel se carga y registramos:

    • Email del usuario
    • Fecha/hora de apertura
    • IP Address
    • User Agent (navegador)
    ⚠️ El píxel es invisible — el usuario no sabe que lo estamos rastreando.

    Rastreo de Clics

    Cada link en tu email se reescribe automáticamente para pasar por nuestro servidor.

    Transformación de Links:

    Tu HTML original:

    <a href="https://mitienda.com/ofertas">VER OFERTA</a>

    Se convierte en:

    <a href="https://mailux.gpssoftwarenumberone.com/api/campaigns/123/track-click?url=...&email=..."> VER OFERTA </a>

    Cuando el usuario clickea:

    1. Se registra el clic en nuestra BD
    2. Se redirige automáticamente a la URL original
    3. El usuario no nota nada (es transparente)

    Ver Estadísticas de Rastreo

    1. Ve a "Campañas"
    2. Busca tu campaña
    3. Haz clic en "📊 Estadísticas"
    ✅ Verás aperturas, clics y links más clickeados en tiempo real.

    🎨 Plantillas Predefinidas

    Mailux incluye 5 plantillas profesionales para ahorrar tiempo.

    Cómo Usar una Plantilla

    1. En el modal de "Nueva campaña"
    2. Busca el dropdown "Usar plantilla"
    3. Selecciona una
    4. Se precargará el HTML
    5. Reemplaza las variables ({{...}})

    Plantilla 1: Newsletter

    Perfecta para boletines semanales/mensuales.

    Variables:
    • {{titulo}} — Título principal
    • {{contenido}} — Contenido
    • {{cta_text}} — Texto del botón
    • {{cta_url}} — URL del botón

    Plantilla 2: Promoción

    Para ofertas y promociones destacadas.

    Variables:
    • {{descripcion_oferta}}
    • {{descuento}} — Porcentaje de descuento
    • {{fecha_vencimiento}}
    • {{enlace_oferta}}

    Para nuevos clientes.

    Plantilla 4: Alerta

    Para notificaciones urgentes.

    Plantilla 5: Resumen

    Para resúmenes periódicos.

    ❓ Preguntas Frecuentes

    ¿Cómo cambio mi contraseña?

    No hay auto-reset aún. Contacta a tu administrador.

    ¿Puedo deshacer un envío?

    No puedes revertir, pero puedes PAUSAR en mitad de un envío:

    1. Ve a "Campañas"
    2. Busca la campaña en estado "Enviando..."
    3. Haz clic en "PAUSAR"
    4. Se detiene inmediatamente
    5. Puedes "REANUDAR" después

    ¿Qué es bounce handling?

    Bounce = Email que "rebota" (no puede entregarse)

    Hard bounce: Email no existe → marcado como "bounced"
    Soft bounce: Temporal → se intenta nuevamente

    Mailux detecta automáticamente y excluye bounced de futuros envíos.

    ¿Quién ve que abro los emails?

    Solo tú (a través de Mailux). El tracking es privado.

    El contacto NO sabe que lo rastreamos. El píxel es invisible.

    ¿Cómo me desuscribo?

    Cada email debe incluir {{unsubscribe_link}}.

    Cuando clickea:

    1. Se marca como "unsubscribed"
    2. No recibirá más de esa lista
    3. Otros distribuidores siguen pudiendo enviarle (datos aislados)

    ¿Hay límite de contactos?

    No. Puedes enviar a 1 millón si quieres. Solo depende de tus límites AWS SES.

    ¿Cómo funciona el envío programado?

    1. Creas campaña
    2. Ingresas fecha/hora
    3. Estado = "Programada"
    4. A esa hora, automáticamente se envía
    5. No necesitas hacer nada

    🔧 Troubleshooting

    El login no funciona

    Error: "Credenciales inválidas"

    Soluciones:
    1. ✅ Verifica email y contraseña exactos
    2. ✅ Recuerda que es sensible a mayúsculas
    3. ✅ Si no recuerdas, contacta admin

    No puedo crear una campaña

    Error: "Selecciona una lista"

    Solución:
    1. Primero crea una lista (Menú → Listas)
    2. Sube contactos a la lista (CSV)
    3. Luego crea la campaña

    El email no se ve bien

    Problema: HTML feo en Outlook/Gmail

    Soluciones:
    1. Usa HTML simple (no CSS complejo)
    2. Usa las plantillas predefinidas
    3. Usa tablas en lugar de divs (Outlook)

    ¿Por qué fallaron algunos emails?

    Motivos comunes:
    1. Email inválido (se filtra al subir CSV)
    2. Bounce previo (marcado como bounced)
    3. Unsubscribed (se desinscribió antes)
    4. Problema AWS SES (credenciales inválidas)

    Cómo verificar:
    Ve a Estadísticas → mira tabla "Enviados/Fallidos"

    Las estadísticas no se actualizan

    Soluciones:
    1. Haz clic en "Estadísticas" nuevamente
    2. Si auto-update está ON, espera 2 segundos
    3. Si no, haz clic en botón de actualizar

    ¿El servidor está caído?

    Intenta:

    1. Recarga la página (Ctrl+R o Cmd+R)
    2. Borra cookies (Ctrl+Shift+Delete)
    3. Prueba en otra pestaña/navegador
    4. Si persiste, contacta a tu admin
